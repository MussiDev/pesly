# Logo files

Every `.svg` in this folder is a brand mark copied from the Simple Icons set and rewritten as a
single-colour SVG in the brand colour published by that set. They are shown as small decorative
avatars next to a merchant or an instrument; they are static files, never loaded from a third
party at runtime.

| Field | Value |
|---|---|
| Source | https://github.com/simple-icons/simple-icons (npm package `simple-icons`) |
| Version | 16.34.0 |
| Retrieved | 2026-10-05 |
| License of the files | CC0 1.0 Universal (the package declares `CC0-1.0` and ships its `LICENSE.md`) |

CC0 waives copyright over the files. It does not transfer the trademarks: every mark below
remains the property of its owner and is used here only to identify that company or instrument,
as nominative use. A mark that cannot be redistributed is removed from the catalogs and its
row falls back to the category icon or to the ticker initials.

Each file is rewritten from its source: the single `<path d>` is kept and
`fill` is set to the brand colour. No other element or attribute is kept.
